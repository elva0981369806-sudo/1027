# 🏎️ F1 賽車模擬器 (新手超友善版 / F1 Rookie Simcade)

專為新手量身打造的 F1 賽車模擬遊戲！融合了 **F1 極限速度感（330+ km/h）** 與 **防挫折 / 防起肖輔助系統**，配備動態碳纖維方向盤、雙踏板擬真操控、時光倒流回放機制以及即時電能混合動力。

---

## 🌟 新手友善核心特色（不怕玩到起肖！）

1. **🚦 F1 官方標準五盞紅燈起跑倒數 (FIA Starting Lights)**
   - 進入賽道時，上方會出現 F1 經典的五盞紅燈架。
   - 紅燈以 1 秒間隔依序亮起（🔴 🔴 🔴 🔴 🔴）並發出高頻提示嗶聲。
   - 五盞全亮後會進入隨機 1.2~2.4 秒的屏息等待期，**全部紅燈熄滅時瞬間彈射起跑**！踩滿油門衝向第一彎！
2. **⏸️ 暫停、重新開始與結束功能**
   - 隨時按下鍵盤 **`ESC`** 或 **`P`** 鍵（或右上角「⏸️ 暫停」按鈕），即可呼叫暫停選單。
   - 選單中可一鍵選擇：
     - ▶️ **繼續比賽** (Resume)
     - 🔄 **重新開始本場比賽** (Restart Race，重置發車格與五燈起跑)
     - 🏁 **結束並返回選單** (Exit to Menu)
3. **🛡️ 智慧循跡防滑系統 (TCS 100%)**
   - 出慢速髮夾彎時，就算大腳全踩油門也不會原地打轉 360 度或甩尾失控。
4. **🚦 動態地面行車引導線 (Dynamic Racing Line)**
   - 賽道地面動態變色提示：
     - 🟢 **綠色**：全油門加速區段
     - 🟡 **黃色**：收油/轉向準備區段
     - 🔴 **紅色**：重踩煞車預警區段
5. **🎯 彎道超速輔助減速 (Cornering Speed Assist)**
   - 新手以 300 km/h 衝向減速彎或髮夾彎若忘記煞車，系統會智慧介入輔助修飾車速，防止直接撞牆！
6. **⚡ 時光倒流 5 秒 (Rewind / 經典 F1 閃回機制)**
   - 走線不理想或不小心擦碰護欄？隨時按住 **`R`** 鍵或點擊畫面上的「⚡ 倒轉重來」按鈕，立即平滑倒流 5 秒重跑彎道，完全不需要整圈重來！
7. **🛞 速度感應轉向阻尼與自動平滑回正**
   - 低速時方向盤角度靈敏（方便過急彎）；高速 300 km/h 巡航時自動柔化轉向，新手不會輕輕按一下就瞬間翻車。

## 🎮 控制指南

- **暫停 / 重新起跑**：按 `ESC` 或 `P` 鍵，隨時暫停與重新開始！
- **方向盤轉向**：
  - 鍵盤：`A` / `D` 或 `←` / `→`
  - 滑鼠/觸控：可以直接用滑鼠按住畫面下方的「F1 碳纖維方向盤」進行拖曳轉動！
- **油門踏板 (右側綠色踏板)**：
  - 鍵盤：`W` 或 `↑`
  - 滑鼠/觸控：直接按住右下角綠色踏板，踏板會有 3D 踩踏下壓反饋與深度進度條！
- **煞車踏板 (左側紅色踏板)**：
  - 鍵盤：`S` 或 `↓`
  - 滑鼠/觸控：直接按住右下角紅色踏板，附帶 ABS 防鎖死與煞車盤發紅發光效果！
- **DRS 空力尾翼 (DRS ZONE)**：
  - 直道進入綠色 DRS 區域時按 `空白鍵 (Space)`，尾翼翼片會實體掀起 35°，阻力降低、極速突破 340+ km/h！
- **ERS 油電電能推力 (Push-to-Pass)**：
  - 按住 `Shift` 鍵釋放 160 匹電能馬力，儀表板顯示即時電量，煞車時自動動能回收充電！
- **攝影機視角切換**：
  - 按 `C` 鍵可循環切換：
    1. **第三人稱追焦 (Chase Cam)**：新手最佳視野，視野最廣、容易掌握車身
    2. **車頂經典視角 (T-Cam)**：電視轉播經典車頂進氣口視角
    3. **座艙駕駛視角 (Cockpit Cam)**：沉浸式 Halo 保護架與第一人稱座艙
- **靜音開關**：
  - 按 `M` 鍵切換音效。

## 🚀 啟動方式

1. **直接開啟**：直接雙擊資料夾內的 `index.html` 即可在瀏覽器（Edge / Chrome / Firefox）暢玩！
2. **本機伺服器**：雙擊 `start_game.bat`，會自動啟動 HTTP 伺服器並開啟瀏覽器。
